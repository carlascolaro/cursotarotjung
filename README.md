# Curso de Tarot y Autoconocimiento Jungiano

Landing page del **Curso de Tarot y Autoconocimiento Jungiano** impartido por **Carla Scolaro**, Psicóloga & Coach Integral.

## 📋 Descripción

Un espacio de formación y experiencia donde aprendés tarot aprendiéndote, integrando la mirada jungiana, el trabajo con arquetipos y la lectura del símbolo como vía de autoconocimiento.

- ✨ Diseño moderno y elegante
- 📱 Completamente responsive (móvil, tablet, desktop)
- 🎯 Optimizado para conversión
- ♿ Accesible y semántico
- 🚀 Rápido y ligero (HTML puro + CSS)
- 📊 Secciones bien estructuradas

## 🚀 Cómo Usar

### Opción 1: Descargar y abrir localmente

1. Descarga todos los archivos
2. Abre `index.html` en tu navegador
3. ¡Listo! La página está funcional

### Opción 2: Subir a GitHub Pages

1. Crea un nuevo repositorio en GitHub
2. Sube todos los archivos
3. Ve a Settings → Pages
4. Selecciona "Deploy from a branch" y elige `main`
5. Tu página estará en: `https://tu-usuario.github.io/nombre-repo`

### Opción 3: Subir a un servidor web

1. Sube todos los archivos vía FTP
2. Asegúrate de que `index.html` esté en la raíz
3. ¡Listo!

## 🔧 Personalización

### Cambiar colores

Abre `css/styles.css` y modifica las variables en `:root`:

```css
:root {
    --color-lila: #B8A0D4;
    --color-verde-oliva: #9CAF7D;
    /* ... más colores ... */
}
```

### Cambiar contenido

Edita `index.html` directamente. Los textos están claramente marcados en comentarios HTML.

### Cambiar imágenes

Reemplaza los archivos en la carpeta `images/`:
- `arquetipos.png`
- `lectura-simbolica.png`
- `recorrido.png`
